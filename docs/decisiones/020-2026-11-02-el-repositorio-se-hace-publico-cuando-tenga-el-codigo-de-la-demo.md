# El repositorio se hace público cuando tenga el código de la demo

- **Origen:** SpriteAnimation, 2026-11-02, al pedir el propietario un enlace al repositorio en el documento explicativo de MVP (tarea 6), para que los alumnos tengan el código completo.
- **Contexto:** el repositorio `jumibot/SpriteAnimation` se creó privado en GitHub ese mismo día y aún no tiene el código de la demo, solo documentos y las hojas de sprites.
- **Opciones:** hacerlo público ya y enlazarlo; hacerlo público y enlazarlo cuando haya código; usar otro repositorio.
- **Decisión:** el repositorio sigue privado hasta que tenga el código de la demo. Entonces se hace público y el documento del MVP lo enlaza en «Para practicar» y en Referencias. El documento se cierra ahora sin enlace.
- **Consecuencias:** el trabajo queda en la tarea «Escribir el código de la demo y publicarlo para los alumnos».
- **Estado:** sustituida en cuándo se publica por «Publicar el repositorio ya, con un README».
