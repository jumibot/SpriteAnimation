# Ejemplo mínimo de clases y código

- **Origen:** SpriteAnimation, 2026-10-30, al preparar el documento de visión. El propietario: «Tiene que ser un ejemplo mínimo con las minimas clases y mínimo código».
- **Contexto:** la demo enseña hojas de sprites, MVP e hilos, y sin un límite claro el código crecería con piezas que no enseñan nada.
- **Decisión:** la demo tiene el mínimo de clases y de código con el que se ven los conceptos que enseña. Cada clase cumple un papel y ninguna sobra.
- **Consecuencias:** no se añaden abstracciones, utilidades ni capas que no hagan falta para que se vean los sprites, MVP o los hilos. Cada propuesta de clase o de código nuevo se justifica por el concepto que muestra.
